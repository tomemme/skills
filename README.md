# OpenClaw Skills Collection 🦞

My custom skills for the OpenClaw agent (running in Podman on Omarchy Arch Linux).

## Skills included
- **movie-context** — Enrich any movie/TV scene with accurate filming locations, real animals vs suits, historical/war timelines, climate, and thematic tie-ins. (Tested on 2001: A Space Odyssey Dawn of Man)
- crypto-monitor (coming soon)
- YouTube automation helpers

All skills are plain Markdown + helper scripts. Drop them in `~/.openclaw/workspace/skills/` and they just work.

Star if you use OpenClaw!
